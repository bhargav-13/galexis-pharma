## 3. Modern Design System

### Design Philosophy
**"Precision Pharma — Light & Trustworthy"**

The design language should communicate:
- **Scientific precision** — clean lines, structured layouts, exact spacing
- **Human warmth** — soft tones, approachable typography, warm whites
- **Global credibility** — professional, modern, internationally recognizable
- **Innovation** — subtle animations, forward-looking UI patterns

### Design Principles

| Principle | Application |
|-----------|-------------|
| Clarity first | Never sacrifice readability for aesthetics |
| White space is medicine | Generous padding creates calm and trust |
| Science + warmth | Clinical precision with human-centered softness |
| Purposeful animation | Motion explains; it never decorates randomly |
| Mobile-first | 60%+ pharma B2B browsing is mobile |

## 10. Technical Recommendations

### Tech Stack Options

| Option | Stack | Best For |
|--------|-------|---------|
| A (Simple) | HTML + CSS + JS + PHP | Basic site, easy to maintain |
| B (Modern) | Next.js + Tailwind CSS | Fast, SEO-friendly, scalable |
| C (CMS-based) | WordPress + Elementor | Easy content updates by non-developers |
| D (Full-stack) | Next.js + Node.js + MongoDB | Dynamic products, enquiry management |

### SEO Essentials

| Item | Notes |
|------|-------|
| Meta titles | Every page gets unique title — "[Company] — [Page Name]" |
| Meta descriptions | 150–160 chars, keyword-rich, for all pages |
| Schema markup | Organization, MedicalOrganization, Product schemas |
| Sitemap | XML sitemap submitted to Google Search Console |
| Image alt text | All product and team images have descriptive alt tags |
| Page speed | Target <2.5s LCP, <100ms FID, <0.1 CLS (Core Web Vitals) |
| HTTPS | SSL certificate mandatory |

### Accessibility

| Standard | Notes |
|----------|-------|
| WCAG 2.1 AA | Minimum compliance for pharma sites |
| Color contrast | All text must meet 4.5:1 contrast ratio |
| Keyboard navigation | Full site navigable via keyboard only |
| Screen reader | ARIA labels on all interactive elements |
| Focus indicators | Visible focus rings on all focusable elements |

### Performance

| Item | Target |
|------|--------|
| Page load time | < 2.5 seconds |
| Image format | WebP with JPEG fallback |
| Lazy loading | All images below the fold |
| Font loading | font-display: swap |
| CDN | Cloudflare or AWS CloudFront |
| Caching | Browser caching headers set |

### Legal & Compliance

| Item | Required |
|------|----------|

| Disclaimer | Yes — pharma regulatory disclaimer |
